## Promotional text

iPhone、iPad、Mac、Apple Watchで使える、あなた専用のヘルパーチーム。計画や調べもの、見守りを引き受け、送信・購入・投稿はあなたの許可を待ちます。

## Description

Nollieは、毎日の暮らしを手伝う小さなヘルパーチームです。チャットや音声、Siriで頼むと、旅行の計画、調べもの、気になることの見守りを引き受け、外出中もMacで作業を進めます。

主導権はあなたに。
• 送信、購入、投稿、削除は、いつもあなたの許可を待ちます。カレンダーの予定、リマインダー、連絡先の追加や変更も同じです。
• ヘルパーが支払い、送信、投稿をする前に、Face IDで本人確認をします。
• Papertrailは、何がなぜオンラインに送られたかを表示します。今週のまとめでは各ヘルパーがしたことを振り返り、ワンタップで一時停止やオフにできます。
• Night shiftは、寝ている間に実行されたことを伝え、すべての項目に「理由」を添えます。

どこにいても。
• チャットはメッセージと同じ感覚で、iPhone、iPad、Macで使えます。
• Apple Watchでは、誰が作業中かを確認し、承認に答えられます。大きな停止ボタンもあります。
• Siri、ショートカット、コントロールセンターから、Nollieに質問したり、すべてのヘルパーを一度に停止したりできます。

すぐに始められます。
• プランナー、買い物、リサーチャー、旅行プランナー、イベント探し、家の用事をワンタップで追加。
• 各ヘルパーが覚えていることを確認して編集できます。
• 保存したカードはMacのキーチェーンに保管されます。ヘルパーに見えるのは「末尾4242のVisa」だけで、支払いのたびにあなたに確認します。

NollieはあなたのMacでHermes Agentを動かします。iPhoneアプリはそこに接続します。
