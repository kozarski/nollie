# Contributing to Nollie

Thank you for wanting to help. Nollie is made by Corey Kozarski, and good bug reports, ideas and pull
requests are all welcome.

## Before you start

- **A bug or a question?** Open an [issue](https://github.com/kozarski/nollie/issues/new/choose). For a
  bug, the diagnostics file from Settings › About › Diagnostics helps a lot.
- **A security problem?** Please don't open an issue. [SECURITY.md](SECURITY.md) says how to report it
  privately.
- **A bigger change?** Open an idea issue first, so we agree on the shape before you spend the time.

## The short version of the rules

The full guide is [Docs/contributing.md](Docs/contributing.md). Build and test commands are in
[Docs/development.md](Docs/development.md).

- Make the smallest complete change that solves the problem.
- Text people see is plain, warm and short, with no em-dashes.
- A change people can see comes with proof you've looked at: a build, the relevant tests and screenshots.
  Use the mock gateway, never your own chats or keys.
- Never commit secrets, personal data or private chats.
- Nollie's characters and icon are Corey's own artwork and are not covered by the code license, so please
  don't reuse them.
- Follow the [code of conduct](CODE_OF_CONDUCT.md).

## Pull requests

Keep each one focused, and say in a sentence or two what it changes and why. The pull request template
has a short checklist. Corey reviews every one, and may ask for changes or decline a change that doesn't
fit where Nollie is going. By sending a pull request you agree that your change is released under the
project's [MIT license](LICENSE).
